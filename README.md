# Terra
A custom framework and application to learn about the basics of graphics programming. Currently I am mostly focusing on 2D rendering.

## :books: Libraries used
* OpenGL (GLAD / GLFW)
* ImGUI
* GLM
* STB (Image)

## :video_game: Controls

### Camera
#### Movement
* Move Up       (UP_KEY)
* Move Down     (DOWN_KEY)
* Move Left     (LEFT_KEY)
* Move Right    (RIGHT_KEY)
* Move forwards  (CTRL + UP_KEY)
* Move backwards (CTRL + DOWN_KEY)

#### Zoom
* Zoom in       (EQUALS_KEY)
* Zoom out      (MINUS_KEY)
