# Terra
A custom framework and application to learn about the basics of graphics programming. Currently I am mostly focusing on 2D rendering and working on a Terraria-esque project.

## :books: Libraries used
* OpenGL (GLAD / GLFW)
* ImGUI
* GLM
* STB (Image)
* PerlinNoise (By Reputeless)

## :video_game: Controls

### Player
#### Movement
* Move Left     (A_KEY)
* Move Right    (D_KEY)
* Jump          (SPACE_KEY)

### Camera
#### Movement
* Move Up       (UP_KEY)
* Move Down     (DOWN_KEY)
* Move Left     (LEFT_KEY)
* Move Right    (RIGHT_KEY)
* Move forwards  (CTRL + UP_KEY)
* Move backwards (CTRL + DOWN_KEY)

#### Zoom
* Zoom in       (EQUALS_KEY OR SCROLL_UP)
* Zoom out      (MINUS_KEY OR SCROLL_DOWN)
